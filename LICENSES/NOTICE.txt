Skvyra digital twin - data licences and notices
================================================

This website shows a 3D model of Skvyra (Kyiv Oblast, Ukraine) built automatically from open data.
Source code and the full processing pipeline: https://github.com/PikalovAndrey/skvyra-digital-twin
This is an independent hobby project. It is not endorsed by any of the data providers below, by the
European Union, ESA or any other entity in charge of the Copernicus programme, by Microsoft, Meta or WRI.

Ground colour
-------------
Contains modified Copernicus Sentinel data 2026 (scene S2C_35UPR_20260718).

Building heights (estimates for large buildings)
------------------------------------------------
GHSL GHS-BUILT-H R2023A (c) European Union 1995-2026, JRC, CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/); changes made: values sampled per building.

Trees
-----
High Resolution Canopy Height Maps v2 (c) Meta and World Resources Institute (WRI), CC BY 4.0;
changes made: canopy segmented into individual trees.
Land cover check: (c) ESA WorldCover project 2021 / Contains modified Copernicus Sentinel data (2021)
processed by ESA WorldCover consortium, CC BY 4.0; used only to decide where the canopy model is outdated.

Other
-----
Landmark coordinates and names: Wikidata (CC0).
Wikimedia Commons photos were used only as visual reference for a few landmarks; no photo is part of
this website. Each building card links to the photo pages with author and licence.
Shevchenko monument on the central square (no building card): the outline of the statue and the
pedestal were estimated from "ТД 1- 08.Сквира.jpg" by Orest Brod (2008-09-15), CC BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/), https://commons.wikimedia.org/wiki/File:ТД_1-_08.Сквира.jpg ;
changes made: only proportions and two colour values were taken, no part of the photo is included; the
figure is a simple silhouette without a likeness.
Kolos stadium: the colours of the running track ring and the multi-sport court are median colours read from
"Skvyra Lev Schwarzburg Kolos Stadium 1" and "... 4" (2021-09-15) by Velyke budivnytstvo / Tulchyn District
State Administration (Велике будівництво / Тульчинська районна державна адміністрація), CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), https://commons.wikimedia.org/wiki/File:Skvyra_Lev_Schwarzburg_Kolos_Stadium_1.jpg ;
changes made: only two colour values were taken, no part of the photos is included.
